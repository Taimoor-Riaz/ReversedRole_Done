# Never Trust Rules

![Never Trust Rules](https://img.itch.zone/aW1nLzI1OTM5NjIyLnBuZw==/original/xZtNVf.png)

**2D psychological puzzle game · Unity · 2026 · Playable in your browser**

🎮 **[Play Never Trust Rules free on itch.io](https://taimoorriaz.itch.io/never-trust-rules)**

Never Trust Rules is a mind-bending 2D game where every instruction could be a trap. The rules on screen may be reversed, misleading, or completely false. Sometimes following them is the right move, and sometimes it is exactly what the game wants you to do.

Think carefully. Question everything. Trust nothing.

## Features

- **Deceptive rule system**: on-screen rules can be reversed, misleading, or false
- **Puzzle and action gameplay** that rewards players who question what they're told
- **Psychological tension** built through level design and pacing
- **WebGL build** that runs directly in the browser

## Tech stack

Unity · C# · 2D · WebGL
